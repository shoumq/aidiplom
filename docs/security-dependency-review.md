# Проверка зависимостей

Дата: 29.10.2026.

## Frontend

`npm audit --omit=dev` сообщил 3 moderate и 3 low проблемы в Nuxt/Nitro и транзитивных зависимостях. Critical/high отсутствуют.

Отложено обновление по GHSA-vjh5-4x84-xrqp и GHSA-gcqx-w48m-w2h4: предложенная npm команда использует `--force`, переводит проект с Nuxt 3 на Nuxt 4 и требует миграции. Риск снижен тем, что backend не проксируется через Nuxt route rules, доступ к данным проверяется непосредственно FastAPI, а security headers должны также устанавливаться внешним reverse proxy. Повторно проверить до production-релиза или не позднее 30.11.2026.

## Backend

Первичный аудит обнаружил advisory в Requests 2.32.5 и Starlette 0.45.3. Выполнено обновление до Requests 2.34.2 и FastAPI 0.162.0/Starlette 1.10.0; повторный аудит этих библиотек чист. Прямые production-зависимости закреплены точными версиями в `requirements.txt`, pip в образе обновлён до 26.2.2. Перед каждым релизом запускать `pip-audit -r requirements.txt` и обновлять версии после проверки совместимости и тестов.
